# TraeCheck

TraeCheck 是一个 Windows 桌面应用，用于管理已登录的 TRAE 桌面账号，并执行每日签到。它从当前 TRAE 桌面客户端读取账号凭据，在本地保存后用于手动、批量和定时签到。

## 功能

- 导入当前 TRAE 桌面账号，支持多个账号独立管理
- 编辑账号显示名称、启用或停用账号
- 单账号签到与一键签到全部已启用账号
- 自动识别当日签到状态，未签到时发起领取
- 每日定时签到，按失败重试次数和间隔执行
- 签到结果日志：可查看全部、成功或失败记录，也可清空日志
- 单账号签到成功后查询并更新该账号的总积分
- 定时签到的成功和失败桌面通知

## 使用前提

- Windows 系统
- 已安装并登录 TRAE 桌面客户端
- 导入账号前，先在 TRAE 桌面客户端切换到需要导入的目标账号

开发环境还需要：

- Node.js 18 或更高版本
- pnpm

## 本地开发

```bash
pnpm install
pnpm dev
```

构建 Windows 安装包：

```bash
pnpm build
```

构建产物输出到 `release` 目录。

## 使用说明

### 1. 导入账号

1. 在 TRAE 桌面客户端登录，并切换到要使用的账号。
2. 打开 TraeCheck，在“账号管理”页点击“添加账号”。
3. 点击“导入当前 TRAE 桌面账号”。

导入会读取当前桌面客户端的登录信息，并以该账号在 TRAE 中的名称创建或更新本地账号记录。若需添加其他账号，请先在 TRAE 桌面客户端切换账号，再重复导入操作。

### 2. 手动签到

- 在账号卡片中点击“立即签到”，仅处理该账号。
- 在账号管理页点击“一键签到全部”，依次处理所有已启用账号。

每次签到会先读取当日签到状态；已经签到的账号会直接记录为“今日已签到”，否则会执行签到领取。批量签到会在账号之间短暂间隔，并按设置重试失败项。

单账号签到成功后，应用会查询该账号的总积分并刷新卡片显示。

### 3. 定时签到

在“设置”页中：

1. 打开“启用自动签到”。
2. 选择每日执行时间。
3. 设置失败重试次数与重试间隔。
4. 按需开启成功或失败通知。

定时任务使用 `Asia/Shanghai` 时区，只处理已启用账号。应用必须保持运行；关闭应用后，定时任务不会继续执行。

### 4. 账号凭据与失效处理

导入的 TRAE 桌面凭据使用 Electron `safeStorage` 加密保存。签到前如检测到短期凭据即将过期，应用会尝试刷新；若刷新失败或凭据已失效，请在 TRAE 桌面客户端重新登录目标账号后再次导入。

## 日志与本地数据

每一次签到尝试都会写入本地日志，包含时间、账号、结果、详情和本次获得的积分（如有）。日志最多保留 500 条，可在“签到日志”页按结果筛选或清空。

账号信息、设置和日志均保存在本机；其中已导入的桌面凭据经过 Electron `safeStorage` 保护。请妥善保管本机和 TRAE 账号。

## 注意事项与排查

- **无法导入账号**：确认 TRAE 桌面客户端已安装、已登录，并已切换到目标账号。
- **签到失败**：检查网络连接和凭据状态；必要时重新登录 TRAE 桌面客户端并重新导入账号，然后查看签到日志中的具体信息。
- **自动签到未执行**：确认自动签到开关已开启、时间设置正确、账号处于启用状态，并保持应用运行。
- **积分未更新**：签到结果与积分查询是两个步骤；若查询失败，可稍后再次执行单账号签到以刷新总积分。

TRAE 的服务接口或客户端存储格式发生变化时，账号导入、签到或积分查询可能受到影响。本工具仅供学习与个人使用，请遵守 TRAE 的服务条款。

│   ├── stores/app.ts           # 前端状态管理
│   ├── App.vue                 # 根组件
│   └── main.ts                 # 渲染进程入口
