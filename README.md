# TraeCheck - Trae Work 每日自动签到工具

一个基于 Electron + Vue 3 开发的 Trae Work 每日自动签到桌面应用，支持多账号管理和定时自动签到。

## ✨ 功能特性

- 🎯 **多账号支持** - 管理多个 Trae Work 账号，一键批量签到
- ⏰ **定时自动签到** - 每天指定时间自动执行签到，无需手动操作
- 🌐 **Webview 模式** - 内置浏览器自动点击签到，无需复杂配置
- ⚡ **API 模式** - 直接调用签到接口，速度更快（需自行抓包）
- 📊 **签到日志** - 完整记录每次签到的时间、结果和详情
- 🔔 **桌面通知** - 签到成功/失败时推送桌面通知
- 🔄 **失败重试** - 签到失败自动重试，可配置重试次数和间隔
- 💾 **本地存储** - 所有数据本地加密存储，安全可靠

## 📖 使用说明

### 1. 添加账号

1. 点击右上角「添加账号」按钮
2. 填写账号备注名（如：主号、小号1）
3. 获取 Cookie（两种方式）：
   - **推荐方式**：点击「通过登录窗口获取」，在弹出的窗口中登录 Trae Work，登录完成后点击页面右上角的「已登录，获取 Cookie」按钮
   - **手动方式**：浏览器打开 work.trae.cn 登录后，按 F12 → Application → Cookies → 复制全部内容粘贴到输入框
4. 点击「添加账号」

### 2. 手动签到

- **单个账号签到**：在账号卡片上点击「立即签到」按钮
- **一键全部签到**：点击右上角「一键签到全部」按钮

### 3. 自动签到设置

1. 进入「设置」页面
2. 开启「启用自动签到」
3. 设置每日签到时间（默认 08:00）
4. 可选：配置失败重试次数和间隔
5. 可选：开启/关闭桌面通知

> ⚠️ 自动签到需要应用保持运行状态，关闭应用后定时任务将停止。

### 4. 签到模式

#### Webview 模式（推荐）

- 无需额外配置
- 程序自动打开内置浏览器，查找并点击签到按钮
- 适合大多数用户使用

#### API 模式

- 速度更快，资源占用更少
- 需要自行抓包获取签到接口信息
- 适合有一定技术基础的用户

**抓包方法**：
1. 浏览器打开 Trae Work 并登录
2. 按 F12 打开开发者工具，切换到 Network 面板
3. 手动点击签到按钮
4. 在请求列表中找到签到相关的请求
5. 复制请求 URL、Method、Headers 和 Body 到设置中

## 🔒 数据安全

- 所有账号数据（Cookie、设置等）均存储在本地
- 使用 electron-store 进行加密存储
- 数据不会上传到任何第三方服务器
- 建议定期备份重要账号数据

## ⚠️ 注意事项

1. **Cookie 有效期**：Cookie 有一定有效期，失效后需重新获取
2. **应用运行**：自动签到需要应用保持运行状态
3. **网络环境**：确保网络连接正常，否则签到可能失败
4. **账号安全**：请妥善保管账号信息，不要分享给他人
5. **使用风险**：请合理使用，遵守平台服务条款

## 🐛 常见问题

**Q: 签到失败怎么办？**
A: 检查以下几点：
- Cookie 是否过期，尝试重新获取
- 网络连接是否正常
- 账号是否被限制
- 查看签到日志了解具体错误信息

**Q: 自动签到不执行？**
A: 确认：
- 自动签到开关已开启
- 签到时间设置正确
- 应用处于运行状态
- 账号已启用自动签到

**Q: Webview 模式找不到签到按钮？**
A: 可能是页面结构变化了，可以：
- 尝试切换到 API 模式
- 等待应用更新适配新页面
- 自行抓包使用 API 模式
